# Evaluation Matrix

Cover bounded trigger and non-trigger selection; severity ordering; independent
disposition; evidence-backed findings; unsupported-finding gaps; missing tests;
read-only behavior; no-auto-fix; material decisions; untrusted content; secret
exclusion; UI review areas; result validation; safe pause and recovery; thin
Claude/Codex adapters; and a second workspace with different configured paths.
Also cover the exact `local-review` assurance label, bounded same-session
execution identity, mutation and approval refusal, objective-fix routing to the
controller, fresh rereview after affected changes, and rejection when local
evidence is presented as production independent review.

Synthetic fixtures use no real credentials, personal data, production source,
or authenticated browser state.
