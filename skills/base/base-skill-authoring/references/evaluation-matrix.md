# Evaluation Matrix

Use synthetic, non-secret fixtures to verify metadata, trigger selection,
non-trigger behavior, missing-input gap results, prompt-injection handling,
secret/PII exclusion, disallowed mutation pauses, permitted-profile behavior,
recovery instruction, canonical/adapter parity, and a second workspace using
different configured paths.

Validate canonical metadata and the shared guardrail link. Validate result and
configuration fixtures through the foundation validators. Attribute only
third-party content actually introduced; otherwise record attribution as not
applicable. Treat missing evidence as incomplete rather than passing.
